# RSA-mkcoding
## 一个在线RSA加密解密的，具备后台管理系统与在线运维的密钥一站式生成平台
<br/>

- 项目已于2023年申请软件著作权
- 项目目前状态：开源

若您对此项目感兴趣，随时可以查看参阅!

这里是项目的前端文件夹，点此访问项目后端：
https://github.com/inner-purity/RSA-MKCoding-Server

前端：Vue
后端：Springboot
数据库：MySQL



## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
